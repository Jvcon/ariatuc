# ariatuc Documentation

Welcome to ariatuc documentation. This project consists of two main components:

## Components

### 🔌 [aria2rpc](aria2rpc/) - RPC Client Library
A standalone Python client library for aria2's RPC interface.

**Status**: 95% complete

- [Getting Started](aria2rpc/getting-started.md)
- [WebSocket Guide](aria2rpc/websocket.md)
- [BitTorrent & Metalink](aria2rpc/bittorrent-metalink.md)
- [Testing Guide](aria2rpc/testing.md)
- [Architecture](aria2rpc/architecture.md)

### 🖥️ [ariatuc](ariatuc/) - Terminal User Interface
A TUI application built on top of aria2rpc for managing downloads.

**Status**: 25% complete

- [Quick Start](quick-start.md)
- [Installation](installation.md)
- [User Guide](ariatuc/user-guide.md)
- [Development](ariatuc/development.md)
